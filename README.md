## Что внутри

Главное меню с двумя разделами.

| Раздел | Что делает |
| --- | --- |
| **Команды** | 14 генераторов команд с переключателем версии игры |
| **Карта сида** | Слайм-чанки и структуры в Поверхности, Аду и Энде |

## Команды

Заполните поля, скопируйте готовую команду и вставьте в чат или командный блок.

| Генератор | Возможности |
| --- | --- |
| **Give** | имя и цвет, описание, зачарования, атрибуты, неразрушаемость, скрытие подсказок, прочность, CustomModelData, Can place on / Can destroy, зелья, текстура головы |
| **Summon** | имя, флаги (без ИИ, неуязвимость и др.), здоровье, скорость, урон, предметы, броня, пассажир, теги |
| **Setblock** | направление, ось, половина, возраст, `waterlogged`, `lit`, состояния, NBT |
| **Effect** | выдача и снятие, бесконечная длительность, скрытие частиц |
| **Enchant** | любое зачарование и уровень |
| **Gamemode** | режим игрока и `defaultgamemode` |
| **Teleport** | координаты, существо, поворот, взгляд на точку или существо |
| **Kill** | цель с фильтрами |
| **Tellraw** | цвета (в том числе `#rrggbb`), стили текста, клик, hover, вставка |
| **Playsound** | источник, позиция, громкость, высота, минимальная громкость |
| **Particle** | разброс, скорость, режим, цвет и размер `dust`, получатели |
| **Bossbar** | все действия `add`, `set`, `get`, `remove`, `list` |
| **Team** | создание, участники, все настройки `modify` |
| **Scoreboard** | цели, значения игроков, `operation`, `setdisplay` |

**Общие возможности**

- Фильтры цели для `@p`, `@a`, `@e` и других: тип, имя, дистанция, лимит, сортировка, режим игры, тег.
- Подсказки при вводе предметов, блоков, существ, эффектов, зачарований, частиц и звуков. Можно ввести и любое своё значение.
- Счётчик длины команды в Give с предупреждением, что чат принимает до 256 символов.

### Версии игры

Синтаксис меняется вместе с выбранной версией.

| Пункт в списке | Что меняется |
| --- | --- |
| `1.12.x` | числовые ID зачарований, `ench`, данные предмета, `§`-коды в именах |
| `1.13 – 1.20.4` | NBT-теги и JSON-имена |
| `1.20.5 – 1.21.4` | компоненты предметов |
| `1.21.5 и новее` | новый формат компонентов, `click_event`, `hover_event` |

Выбранная версия запоминается в браузере.

## Карта сида

Введите сид (число или текст) или нажмите «Случайный».

- Перетаскивание карты, колесо мыши и кнопки `+` / `−`.
- Переход по координатам X и Z, координаты и чанк под курсором.
- Клик по маркеру показывает координаты структуры и копирует их.

| Измерение | Слои |
| --- | --- |
| **Поверхность** | слайм-чанки, деревня, пустынная пирамида, иглу, храм в джунглях, хижина ведьмы, застава разбойников, океанский монумент, лесной особняк, разрушенный портал, кораблекрушение, океанские руины, древний город, руины тропы, камеры испытаний |
| **Ад** | нижняя крепость, бастион, разрушенный портал |
| **Энд** | города Энда, врата Энда |

### Насколько карта точна

- **Слайм-чанки** считаются по алгоритму Java и должны совпадать с игрой.
- **Структуры** показаны по сетке генерации. Игра ставит структуру только в подходящем биоме, а биомов на карте нет, поэтому часть маркеров в реальном мире отсутствует.
- Параметры сетки записаны по памяти и в игре не проверялись.
- Карта рассчитана на Java и формат генерации 1.18 и новее.

Если нужны точные биомы, используйте [Cubiomes Viewer](https://github.com/Cubitect/cubiomes-viewer) или подключите библиотеку [cubiomes](https://github.com/Cubitect/cubiomes) в виде WebAssembly-модуля.

## Запуск

Весь сайт лежит в одном файле `index.html`.

```bash
# вариант 1: просто откройте файл в браузере
open index.html

# вариант 2: локальный сервер
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

**Публикация.** Положите `index.html` на любой статический хостинг: GitHub Pages, Netlify или Cloudflare Pages. Сборка не нужна.

## Структура проекта

```text
site/
├── index.html            весь сайт: меню, генераторы, карта сида
├── registry.yml          список имён для подсказок (сайтом не используется)
├── tools/
│   └── gen_registry.py   сборка полного реестра из отчётов сервера Minecraft
└── README.md
```

> `registry.yml` и `gen_registry.py` остались от удалённой подгрузки реестра. Сайт работает на встроенных списках и этих файлов не читает.

Чтобы получить полные списки для своей версии, скрипт можно запустить отдельно:

```bash
java -DbundlerMainClass=net.minecraft.data.Main -jar server.jar --reports --server
python3 tools/gen_registry.py generated > registry.yml
```

## Известные ограничения

- Команды для 1.20.5 и новее проверены только на синтаксис страницы, в игре не запускались. В этих версиях формат менялся часто.
- В 1.12 недоступны часть функций: hex-цвета, поворот к точке и другие.
- Только Java Edition, Bedrock не поддерживается.
- Нет импорта готовой команды обратно в форму.
- Нет яйца призыва и спавнера в Summon, нескольких фрагментов текста в Tellraw, фейерверков и баннеров.
- На карте сида нет биомов, спавна, крепостей Верхнего мира, поиска сидов и истории.
