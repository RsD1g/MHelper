## 📦 Что внутри

Весь проект работает автономно в браузере и разделён на три инструмента:

| Раздел | Описание |
| :--- | :--- |
| 🛠️ **Команды** | 14 визуальных генераторов команд с автодополнением и адаптацией под выбранную версию игры |
| 🗺️ **Карта сида** | Просмотр биомов, слайм-чанков и структур в Поверхности, Аду и Энде на базе **cubiomes (WASM)** |
| 📦 **Компилятор** | Быстрая упаковка готовых `.class`-файлов и манифеста мода в рабочий `.jar`-архив прямо в браузере |

## 🛠️ Генераторы команд

Заполните нужные поля, скопируйте готовую команду в один клик и вставьте её в чат или командный блок.

* **Умные фильтры целей:** удобная настройка селекторов `@p`, `@a`, `@e`, `@r`, `@s` (тип, имя, дистанция, лимит, сортировка, режим игры, теги).
* **Автоподсказки:** встроенные базы предметов, блоков, существ, эффектов, зачарований, частиц и звуков (можно вводить и кастомные ID).
* **Контроль длины:** счётчик символов в `/give` с предупреждением о лимите чата в 256 символов.

<details>
<summary><b>📋 Показать список всех 14 генераторов и их возможности</b></summary>
<br>

| Команда | Доступные настройки |
| :--- | :--- |
| **`/give`** | Имя и цвет, лор, зачарования, атрибуты, неразрушаемость, скрытие флагов, прочность, `CustomModelData`, `CanPlaceOn` / `CanDestroy`, эффекты зелий, текстура головы |
| **`/summon`** | Имя, флаги (`NoAI`, `Invulnerable` и др.), здоровье, скорость, урон, предметы в руках, броня, пассажир, теги |
| **`/setblock`** | Направление, ось, половина блока, возраст, `waterlogged`, `lit`, состояния блока и NBT |
| **`/effect`** | Выдача и снятие эффектов, бесконечная длительность (`infinite`), скрытие частиц |
| **`/enchant`** | Выбор любого зачарования и его уровня |
| **`/gamemode`** | Смена режима игрока и настройка `defaultgamemode` |
| **`/teleport`** | Координаты, сущность, поворот камеры, взгляд на точку или другое существо |
| **`/kill`** | Уничтожение целей с настройкой селекторов и фильтров |
| **`/tellraw`** | HEX-цвета (`#rrggbb`), стили текста, события при клике (`click_event`), наведении (`hover_event`) и вставке |
| **`/playsound`** | Источник звука, координаты, громкость, высота тона (`pitch`), минимальная громкость |
| **`/particle`** | Разброс по осям, скорость, режим отображения, цвет и размер для `dust`, получатели |
| **`/bossbar`** | Все действия: `add`, `set`, `get`, `remove`, `list` |
| **`/team`** | Создание команд, управление участниками, все параметры `modify` |
| **`/scoreboard`** | Цели, очки игроков, математические операции (`operation`), отображение (`setdisplay`) |

</details>

### Версии игры

Синтаксис генерируемых команд автоматически перестраивается при смене версии (выбор сохраняется в браузере):

| Версия | Особенности синтаксиса |
| :--- | :--- |
| **`1.12.x`** | Числовые ID зачарований, тег `ench`, метаданные предметов, `§`-коды форматирования |
| **`1.13 – 1.20.4`** | Классические NBT-теги и JSON-формат текста |
| **`1.20.5 – 1.21.4`** | Переход на компоненты предметов (`[...]`) |
| **`1.21.5 и новее`** | Актуальный формат компонентов, обновлённые `click_event` и `hover_event` |

## 🗺️ Карта сида

Введите цифровой или текстовый сид (либо сгенерируйте случайный) для просмотра мира **Java Edition (от 1.12.2 и новее)**.

* **Навигация:** плавное перетаскивание, масштабирование колесом мыши или кнопками `+` / `−`, быстрый телепорт по координатам `X` и `Z`.
* **Интерактивность:** отображение координат блока и чанка под курсором; клик по иконке структуры показывает её точные координаты и копирует их.

| Измерение | Отображаемые слои |
| :--- | :--- |
| 🌿 **Поверхность** | Биомы, слайм-чанки, деревни, пустынные пирамиды, иглу, храмы в джунглях, хижины ведьм, аванпосты, монументы, особняки, разрушенные порталы, затонувшие корабли, руины океана, древние города, руины троп, камеры испытаний |
| 🔥 **Ад (Nether)** | Биомы, адские крепости, бастионы, разрушенные порталы |
| 🌌 **Энд (End)** | Биомы, города Энда, врата Энда |

> [!NOTE]
> **Точность расчётов:** слайм-чанки и биомы поверхности рассчитываются точно по алгоритмам генерации выбранной версии с помощью встроенной библиотеки [cubiomes](https://github.com) (WebAssembly). Для некоторых структур (например, пустынных храмов и лесных особняков) проверка высоты рельефа не выполняется, поэтому единичные маркеры на карте могут отсутствовать в самой игре.

## 📦 Компилятор (JAR)

Вспомогательный инструмент для быстрой сборки модов (Fabric / Forge) без установки JDK на устройство:
1. Подготовьте `.zip`-архив с уже скомпилированными `.class`-файлами и манифестом (`fabric.mod.json` или `META-INF/mods.toml`).
2. Перетащите архив в окно загрузки.
3. Скачайте готовый к запуску `mod.jar`.

*(Компиляция исходного кода `.java` в байт-код в браузере не выполняется).*

## 🚀 Запуск и публикация

Весь интерфейс, логика и WebAssembly-модуль упакованы в единственный файл **`index.html`**.

```bash
# Вариант 1: открыть напрямую в любом современном браузере
open index.html

# Вариант 2: запустить через локальный веб-сервер
python3 -m http.server 8000
# После этого сайт будет доступен по адресу http://localhost:8000
```

> [!TIP]
> **Бесплатный хостинг:** просто загрузите `index.html` в репозиторий на **GitHub Pages**, **Netlify** или **Cloudflare Pages** — проект заработает сразу без настройки сборщиков.

<details>
<summary><b>🗂️ Структура репозитория и утилиты</b></summary>
<br>

```text
site/
├── index.html            # Весь сайт: меню, генераторы, карта сида и упаковщик JAR
├── registry.yml          # Реестр ID для автодополнения (резервная копия, сайтом не читается)
├── tools/
│   └── gen_registry.py   # Python-скрипт для парсинга отчётов сервера Minecraft
└── README.md
```

Если выйдет новая версия игры и потребуется обновить списки ID из официального `server.jar`:

```bash
java -DbundlerMainClass=net.minecraft.data.Main -jar server.jar --reports --server
python3 tools/gen_registry.py generated > registry.yml
```

</details>

## ⚠️ Известные ограничения и планы

**Текущие ограничения:**
* Поддерживается только **Minecraft Java Edition** (генерация Bedrock не поддерживается).
* Синтаксис версий `1.20.5+` нуждается в дополнительной проверке в игре из-за частых изменений формата компонентов.
* В `1.12.x` недоступны функции более новых версий (например, HEX-цвета или поворот взгляда к точке в `/tp`).
* Пока отсутствует обратный импорт готовой команды в форму, а также генераторы фейерверков, баннеров и спавнеров.

**В планах:**
- [ ] Обратный парсинг (импорт) готовых команд в поля генератора
- [ ] Новые генераторы: `/attribute`, `/damage`, `/ride`, `/rotate`, Block Display и Falling Block
- [ ] Конструктор баннеров, фейерверков и кастомных спавнеров
- [ ] Поиск сидов по заданным критериям и отображение точки спавна
