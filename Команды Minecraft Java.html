Карта только для Java, формат генерации 1.18 и новее. В Аду и Энде координаты даны в этом измерении. Слайм-чанки считаются точно. Маркеры структур показывают места по сетке генерации: игра ставит структуру только в подходящем биоме, а биомов на этой карте нет, поэтому часть маркеров в игре отсутствует. Параметры сетки записаны по памяти и в игре не проверялись.
